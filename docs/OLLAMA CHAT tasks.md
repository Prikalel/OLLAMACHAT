# Расширения и полезные Nuget-пакеты

- ✅ **Microsoft.CodeAnalysis.CSharp (Roslyn)**
  - Основная библиотека для парсинга, анализа синтаксиса, построения дерева вызовов, обработки типов, вызовов, интерфейсов и наследования. Позволяет обрабатывать любые связи, включая зависимости по методу-классу, объекту, типу данных.
- **Microsoft.Extensions.StaticAnalysis**
  - Собрание полезных analyzers для статической проверки C#-кода, может помочь с детектированием спорных зависимостей.
  - **SonarAnalyzer.CSharp** - проверяет S1541 и S3776
  - **Microsoft.CodeAnalysis.NetAnalyzers** - проверяет CA1502 и CA1505
- **NsDepCop**
  - Позволяет явно контролировать связи между неймспейсами и сборками, возможно будет полезен как пример парсера, если захочется расширить правила под Unity-игру. Работает как статический анализатор и использует Roslyn внутри.
- **Call-Graph-Builder-DotNet**
  - Open-source проект на Roslyn, строящий граф вызовов методов (call relations), в том числе по интерфейсам: https://github.com/too4words/Call-Graph-Builder-DotNet — особенно полезен если требуется именно отслеживать runtime call relations, а не только типовые зависимости.
- **Microsoft.Unity.Analyzers**
  - Если проект — Unity, этот пакет содержит analyzers специфичные для Unity API и стилевых особенностей. Для «глубокого парсинга» нужен именно Roslyn.

# примеры (чтобы посмотреть как загрузка зависимостей реализуется в других построителях графа)

- **DependenSee**
  - Кроссплатформенный CLI с открытым исходным кодом: https://github.com/madushans/DependenSee
  - Строит граф классов, пакетов, пространств имён на основе исходников и/или решения.
  - Вывод в HTML, DOT, JSON, поддержка фильтров и большой гибкости.
  - В коде реализован собственный разбор дерева зависимостей — можно посмотреть, как устроена внутренняя логика парсинга (Roslyn) и вывода.
- **DependencyGraph (marccarre)**
  - Open-source CLI на C#: https://github.com/marccarre/DependencyGraph
  - Работает через Reflection/DLL, генерирует дерево зависимостей по множеству критериев: интерфейсы, наследование, аргументы методов, поля, переменные.
  - Выводит граф классов и их связей в текстовом формате, который можно потом визуализировать (например, через Graphviz).
  - Лицензия Apache-2.0, подробные unit-тесты и легкая архитектура парсинга.
- **Graphviz** - для рендера графа
  - Есть множество примеров на GitHub, по запросу “dependency-graph” — можно изучить структуру, кастомизировать вывод, и анализировать детали реализации.
- **D3** - рендер через javascript

# Диаграммы
- **PlantUmlClassDiagramGenerator**  
  CLI-инструмент и Source Generator для генерации класс-диаграмм в формате PlantUML из C# исходников.  
  - GitHub: https://github.com/pierre3/PlantUmlClassDiagramGenerator  
  - Под капотом: Roslyn Syntax API для парсинга дерева кода, анализа модификаторов, свойств, методов и отношений (наследование, ассоциации). Поддерживает фильтры (например, по доступности) и опции вроде -createAssociation для связей через поля/свойства.  

- **PlantUmlClassDiagramGenerator.SourceGenerator**  
  NuGet-пакет, интегрирующийся как Roslyn Source Generator для автоматической генерации PlantUML во время компиляции.  
  - NuGet: https://www.nuget.org/packages/PlantUmlClassDiagramGenerator.SourceGenerator  
  - Под капотом: Roslyn Symbols для анализа (более точный, чем SyntaxTree), генерирует диаграммы с учетом generics, nested классов и инициализаторов. Работает на уровне компилятора, без отдельного запуска.
