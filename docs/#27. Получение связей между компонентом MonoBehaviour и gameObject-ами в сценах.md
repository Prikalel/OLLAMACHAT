# Решение для анализа Unity компонентов без Unity Engine

## Рекомендуемый подход

На основе ваших требований и ограничений (чистая машина только с .NET 9 SDK), наилучшим решением является комбинация **VYaml** и **YamlDotNet** для парсинга Unity YAML файлов с дополнительной логикой для сопоставления GUID'ов.

## Основные компоненты решения

### 1. YAML парсер для Unity файлов

**VYaml** - специально оптимизированная библиотека для Unity YAML форматов:

```xml
<PackageReference Include="VYaml" Version="2.0.0" />
```

Ключевые преимущества VYaml:[1]
- Поддерживает специфичный Unity YAML формат (включая "stripped" документы)
- В 6 раз быстрее YamlDotNet
- Гораздо меньше памяти использует
- Нативная поддержка Unity serialization format

### 2. Структура сервиса

```csharp
public class UnityRelationshipService
{
    private readonly Dictionary<string, string> _guidToScriptMap = new();
    private readonly Dictionary<string, List<GameObjectReference>> _componentToGameObjects = new();

    public async Task<UnityReferencesResult> AnalyzeProjectAsync(string projectPath)
    {
        // 1. Сначала сканируем .cs.meta файлы для создания GUID -> script mapping
        await BuildGuidToScriptMappingAsync(projectPath);
        
        // 2. Затем анализируем все .unity и .prefab файлы
        await AnalyzeScenesAndPrefabsAsync(projectPath);
        
        return new UnityReferencesResult 
        {
            UnityReferences = _componentToGameObjects.Select(kvp => new ComponentReference
            {
                FromFullTypeName = kvp.Key,
                ToGameObjects = kvp.Value
            }).ToList()
        };
    }
}
```

### 3. Парсинг .cs.meta файлов для GUID mapping

```csharp
private async Task BuildGuidToScriptMappingAsync(string projectPath)
{
    var metaFiles = Directory.GetFiles(projectPath, "*.cs.meta", SearchOption.AllDirectories);
    
    foreach (var metaFile in metaFiles)
    {
        var content = await File.ReadAllTextAsync(metaFile);
        var parser = YamlParser.FromText(content);
        
        // Ищем guid в meta файле
        while (parser.Read())
        {
            if (parser.CurrentEventType == ParseEventType.Scalar && 
                parser.TryGetScalarAsString(out var scalar) && 
                scalar == "guid")
            {
                parser.Read(); // переходим к значению
                if (parser.TryGetScalarAsString(out var guid))
                {
                    var scriptPath = metaFile.Replace(".meta", "");
                    var className = ExtractClassNameFromScript(scriptPath);
                    if (!string.IsNullOrEmpty(className))
                    {
                        _guidToScriptMap[guid] = className;
                    }
                }
                break;
            }
        }
    }
}
```

### 4. Извлечение полного имени класса из C# файла

> Тут можно использовать roslyn для получения информации о том, какой класс определён в cs файле.

```csharp
private string ExtractClassNameFromScript(string scriptPath)
{
    if (!File.Exists(scriptPath)) return null;
    
    var content = File.ReadAllText(scriptPath);
    
    // Простой regex для поиска MonoBehaviour классов
    var namespaceMatch = Regex.Match(content, @"namespace\s+([^\s{]+)");
    var classMatch = Regex.Match(content, @"class\s+(\w+)\s*:\s*.*MonoBehaviour");
    
    if (classMatch.Success)
    {
        var className = classMatch.Groups[1].Value;
        var namespaceName = namespaceMatch.Success ? namespaceMatch.Groups[1].Value : "";
        
        return string.IsNullOrEmpty(namespaceName) ? className : $"{namespaceName}.{className}";
    }
    
    return null;
}
```

### 5. Анализ Unity scene и prefab файлов

```csharp
private async Task AnalyzeScenesAndPrefabsAsync(string projectPath)
{
    var unityFiles = Directory.GetFiles(projectPath, "*.unity", SearchOption.AllDirectories)
        .Concat(Directory.GetFiles(projectPath, "*.prefab", SearchOption.AllDirectories));
    
    foreach (var file in unityFiles)
    {
        await AnalyzeUnityFileAsync(file);
    }
}

private async Task AnalyzeUnityFileAsync(string filePath)
{
    var content = await File.ReadAllTextAsync(filePath);
    var parser = YamlParser.FromText(content);
    
    var gameObjects = new Dictionary<long, GameObjectInfo>();
    var monoBehaviours = new List<MonoBehaviourInfo>();
    
    // Первый проход: собираем все GameObjects
    while (parser.Read())
    {
        if (parser.CurrentEventType == ParseEventType.DocumentStart)
        {
            // Парсим тег документа для определения типа
            if (parser.TryGetCurrentTag(out var tag) && tag.Value.Contains("!u!1")) // GameObject
            {
                var gameObject = ParseGameObject(parser);
                if (gameObject != null)
                {
                    gameObjects[gameObject.FileID] = gameObject;
                }
            }
            else if (tag.Value.Contains("!u!114")) // MonoBehaviour
            {
                var monoBehaviour = ParseMonoBehaviour(parser);
                if (monoBehaviour != null)
                {
                    monoBehaviours.Add(monoBehaviour);
                }
            }
        }
    }
    
    // Второй проход: связываем MonoBehaviour с GameObject
    foreach (var mb in monoBehaviours)
    {
        if (_guidToScriptMap.TryGetValue(mb.ScriptGuid, out var componentTypeName) &&
            gameObjects.TryGetValue(mb.GameObjectFileID, out var gameObjectInfo))
        {
            var gameObjectRef = new GameObjectReference
            {
                GameObjectName = gameObjectInfo.Name,
                ScenePath = filePath,
                Type = filePath.EndsWith(".unity") ? "scene" : "prefab"
            };
            
            if (!_componentToGameObjects.ContainsKey(componentTypeName))
            {
                _componentToGameObjects[componentTypeName] = new List<GameObjectReference>();
            }
            
            _componentToGameObjects[componentTypeName].Add(gameObjectRef);
        }
    }
}
```

### 6. Парсинг GameObject и MonoBehaviour

```csharp
private GameObjectInfo ParseGameObject(YamlParser parser)
{
    string name = null;
    long fileID = 0;
    
    // Получаем fileID из anchor
    if (parser.TryGetCurrentAnchor(out var anchor))
    {
        long.TryParse(anchor.Value, out fileID);
    }
    
    // Ищем m_Name
    while (parser.Read() && parser.CurrentEventType != ParseEventType.DocumentEnd)
    {
        if (parser.CurrentEventType == ParseEventType.Scalar &&
            parser.TryGetScalarAsString(out var key) && key == "m_Name")
        {
            parser.Read();
            if (parser.TryGetScalarAsString(out name))
                break;
        }
    }
    
    return new GameObjectInfo { FileID = fileID, Name = name };
}

private MonoBehaviourInfo ParseMonoBehaviour(YamlParser parser)
{
    string scriptGuid = null;
    long gameObjectFileID = 0;
    
    while (parser.Read() && parser.CurrentEventType != ParseEventType.DocumentEnd)
    {
        if (parser.CurrentEventType == ParseEventType.Scalar &&
            parser.TryGetScalarAsString(out var key))
        {
            if (key == "m_GameObject")
            {
                // Парсим {fileID: 123456}
                if (ParseFileIDReference(parser, out gameObjectFileID)) continue;
            }
            else if (key == "m_Script")
            {
                // Парсим {fileID: 11500000, guid: xxxx, type: 3}
                if (ParseScriptReference(parser, out scriptGuid)) continue;
            }
        }
    }
    
    return new MonoBehaviourInfo 
    { 
        ScriptGuid = scriptGuid, 
        GameObjectFileID = gameObjectFileID 
    };
}
```

## Альтернативные подходы

### 1. Использование YamlDotNet (запасной вариант)

Если VYaml не подойдёт, можно использовать YamlDotNet с кастомными конвертерами:[2][3]

```csharp
var deserializer = new DeserializerBuilder()
    .WithTagMapping("!u!", "tag:unity3d.com,2011:")
    .IgnoreUnmatchedProperties()
    .Build();
```

### 2. Готовые инструменты для адаптации

**Существующие решения для референса:**
- **unity-scene-analysis** - Go-based tool для анализа Unity сцен[4]
- **unity-guid-mapper** - C# инструмент для работы с GUID'ами[5]
- **AutoUnityGuidRemapper** - быстрый GUID remapper[6]

### 3. Упрощённый regex-подход (если YAML парсинг сложен)

Для быстрого прототипа можно использовать regex для извлечения ключевой информации:

```csharp
// Поиск MonoBehaviour записей
var monoBehaviourPattern = @"--- !u!114 &(\d+)[\s\S]*?m_GameObject: \{fileID: (\d+)\}[\s\S]*?m_Script: \{fileID: 11500000, guid: ([a-f0-9]{32}), type: 3\}";

// Поиск GameObject записей  
var gameObjectPattern = @"--- !u!1 &(\d+)[\s\S]*?m_Name: (.+)";
```

## Развёртывание и использование

1. **Создание консольного приложения**:
```bash
dotnet new console -n UnityRelationshipAnalyzer
cd UnityRelationshipAnalyzer
dotnet add package VYaml
```

2. **Использование**:
```bash
dotnet run -- "C:\Path\To\Unity\Project"
```

Данное решение полностью удовлетворяет вашим требованиям: работает на чистой машине только с .NET 9 SDK, не требует установки Unity Engine, анализирует Unity проекты путём парсинга YAML файлов и GUID сопоставления через .meta файлы.
