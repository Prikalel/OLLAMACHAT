# Схема базы данных Sqlite для анализа UnityEvent

## Обзор

Данный документ описывает схему базы данных Sqlite для хранения информации о UnityEvent и их обработчиках в Unity проектах. База данных будет использоваться для анализа связей между событиями и обработчиками, отслеживания потенциальных и подтвержденных связей.

## Основные принципы проектирования

1. **GUID как первичные ключи**: Стабильные идентификаторы для использования в других системах
2. **Поддержка наследования**: Учет наследования MonoBehaviour и других классов
3. **Отслеживание изменений**: Мягкое удаление с указанием причины
4. **Минимализм**: Хранение только необходимой информации без избыточности

## Таблицы

### 1. UnityEvents

Хранит информацию о найденных UnityEvent в коде проекта.

| Имя колонки | Тип данных | Ограничения | Описание |
|-------------|------------|-------------|----------|
| Id | GUID | PRIMARY KEY, NOT NULL | Уникальный идентификатор события |
| Name | String | NOT NULL | Имя события |
| FullName | String | NOT NULL | Полное имя события включая пространство имен |
| EventType | String | NOT NULL | Тип события (UnityEvent, UnityEvent<T>) |
| GenericTypeArguments | String[] | NULL | Массив типов аргументов для UnityEvent<T> |
| ArgumentsHash | String | NOT NULL | Хэш от массива типов аргументов для быстрого поиска |
| FilePath | String | NOT NULL | Путь к файлу, где определено событие (базовый класс) |
| IsInherited | Boolean | NOT NULL | True, если событие унаследовано от базового класса |
| BaseClassFullName | String | NULL | Полное имя базового класса, если унаследовано |
| LastModified | DateTime | NOT NULL | Время последнего изменения записи |
| IsDeleted | Boolean | NOT NULL, DEFAULT false | Флаг удаления для мягкого удаления |

### 2. EventHandlers

Хранит информацию о методах-обработчиках событий.

| Имя колонки | Тип данных | Ограничения | Описание |
|-------------|------------|-------------|----------|
| Id | GUID | PRIMARY KEY, NOT NULL | Уникальный идентификатор обработчика |
| Name | String | NOT NULL | Имя метода-обработчика |
| FullName | String | NOT NULL | Полное имя метода включая пространство имен |
| ParameterTypes | String[] | NOT NULL | Массив типов параметров метода |
| ArgumentsHash | String | NOT NULL | Хэш от массива типов параметров для быстрого поиска |
| FilePath | String | NOT NULL | Путь к файлу, где определен обработчик (базовый класс) |
| IsInherited | Boolean | NOT NULL | True, если обработчик унаследован от базового класса |
| BaseClassFullName | String | NULL | Полное имя базового класса, если унаследовано |
| IsPublic | Boolean | NOT NULL | True, если метод публичный |
| LastModified | DateTime | NOT NULL | Время последнего изменения записи |
| IsDeleted | Boolean | NOT NULL, DEFAULT false | Флаг удаления для мягкого удаления |

### 3. EventHandlerRelationships

Связующая таблица между событиями и обработчиками.

| Имя колонки | Тип данных | Ограничения | Описание |
|-------------|------------|-------------|----------|
| Id | GUID | PRIMARY KEY, NOT NULL | Уникальный идентификатор связи |
| EventId | GUID | NOT NULL, FOREIGN KEY | Идентификатор события |
| HandlerId | GUID | NOT NULL, FOREIGN KEY | Идентификатор обработчика |
| RelationshipType | String | NOT NULL | Тип связи (Potential, Confirmed, Obsolete) |
| Source | String | NOT NULL | Источник связи (Parser, Inspector, Code, Manual) |
| DeletionReason | String | NULL | Причина удаления (если связь устарела) |
| CreatedAt | DateTime | NOT NULL | Время создания связи |
| UpdatedAt | DateTime | NOT NULL | Время обновления связи |
| IsDeleted | Boolean | NOT NULL, DEFAULT false | Флаг удаления для мягкого удаления |

## Внешние ключи

- `EventHandlerRelationships.EventId` → `UnityEvents.Id`
- `EventHandlerRelationships.HandlerId` → `EventHandlers.Id`

# Перечисления

## Типы связей (RelationshipType)

- **Potential**: Потенциальная связь, определенная по сигнатуре метода
- **Confirmed**: Подтвержденная связь, установленная через инспектор или код
- **Obsolete**: Устаревшая связь (IsDeleted = true, DeletionReason заполнен)

## Источники связей (Source)

- **Inspector**: Установлена через Unity Inspector
- **Code**: Установлена программно в коде
- **Manual**: Установлена вручную через UI

## Причины удаления (DeletionReason)

- **EventDeleted**: Событие было удалено из кода
- **HandlerDeleted**: Обработчик был удален из кода
- **SignatureChanged**: Изменилась сигнатура метода или события
- **ClassDeleted**: Класс был удален или переименован
